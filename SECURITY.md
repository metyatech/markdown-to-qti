# Security Policy

## Supported Versions

The following versions of `markdown-to-qti` are currently being supported with security updates:

| Version | Supported |
| ------- | --------- |
| < 1.0.0 | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it by opening a GitHub Issue.
We will acknowledge your report and provide a timeline for addressing the issue.
