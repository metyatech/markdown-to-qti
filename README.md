# markdown-to-qti

## Overview

This repository will implement a tool that converts Markdown question files into
IMS QTI 3.0. The authoring format is defined in:

- `docs/markdown-question-spec.md`

## Setup

- Install JDK 17+.
- Install Gradle (CLI).

## Development Commands

- Run tests: `gradle test`
